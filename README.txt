Регистрация 
При регистрации пользователя, создается корзина
Авторизация
Ввод логина и пароля происходит при попытке перейти в магазин (возмонжо будет отредактировано)
При успешной авторизации срабатывает обработчик, который ищет корзину пользователя и добавляет в качестве сессионно атрибута
Каталог
При успешной авторизации производится переход на страницу каталога где можно выбрать категорию. Если в категории есть продукты, они отображаются (catalogs/5 - электропечи и catalogs/15 - сковородки)
В категории можно:
1.	Отфильтровать продукты
2.	Добавить новый продукт
3.	Добавить новый фильтр(свойство продукта), возможно добавить 3 типа свойства, NUMBER   FLOAT,    STRING_CLASSIFIER
Справочник
При добавлении свойство с типом справочник(STRING_CLASSIFIER) в последствии его можно редактировать
Продукты
С каталога можно перейти в продукт
Продукт можно:
1.	Купить – добавляется в корзину
2.	Отредактировать свойства:
•	Каждое по отдельности, перейдя по ссылке в названии свойства
•	Обновить сразу все, изменив значение на форме продукта и нажав на кнопку обновить (не очень нравится реализация)
3.	Добавить новое свойство, если оно раннее было создано для категории, если свойство с типом справочник в него можно добавить значение и также удалить. 
4.	Удалить свойство
Корзина
В любой момент можно прейти в корзину в верхнем углу экрана
1.	Обновляется сессионная корзина при обновлении её значения в базе
2.	При переходе в корзину отображается:
•	Cписок продуктов
•	Количество продуктов
•	Суммарная стоимость продукта
•	Суммарная стоимость корзины
•	Общее количество продуктов в корзине
3.	При нажатии на чекбокс продукта запрос на обновление продукта в корзине при этом редактируется информация о заказе:
a.	Галочку поставили, продукт не учитывается при пересчете заказа
b.	Галочку убрали, продукт учитывается при пересчете заказа
4.	При смене количества продуктов отправляется запрос на обновление продукта, при этом:
a.	Пересчитывается количество и стоимость продукта в корзине
Требуется
Обработка исключений:
•	При добавлении в корзину одного и того же продукта, увеличивать количество
Профиль
В любой момент можно перейти в профиль в верхнем углу экрана
Отображается информация о пользователе которую можно редактировать
При смене вкладки отображаются заказы раннее оформленные пользователем
Требуется
1.	Функционал для оформления заказов со всеми его плюшками
2.	Тесты
3.	Оптимизировать запросы
4.	Выполнить ТЗ
5.	Обработка исключений 
6.	Валидация
7.	Привести в порядок фронт
8.	Систематизировать контроллеры
9.	Избавиться от ненужных методов
