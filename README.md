# Доступный функционал:

## Основные функции
1.  Регистрация
2.  Аутентификация
3.  Просмотр и изменение персональных данных
4.  Просмотр каталога + фильтрация по категориям продуктов
5.  Изменение свойств категории
6.  Просмотр и изменение продукта
7.  Изменение свойств продукта
8.  Добавление продукта в корзину
9.  Редактирование корзины
10. Формирование заказа
11. Просмотр заказов

---

## Детализация функционала

### Регистрация
*   При регистрации пользователя автоматически создается корзина.
*   Реализована базовая валидация на отсутствие значения в поле пароля.

### Аутентификация
*   Требуется для всех действий, кроме регистрации и просмотра каталога.
*   При успешной аутентификации срабатывает обработчик, который находит корзину пользователя и добавляет её в качестве сессионного атрибута.

### Каталог
*   При просмотре каталога можно выбрать категорию (навигация закеширована).
*   Продукты отображаются, если они есть в категории (пример: `catalogs/5` - электропечи, `catalogs/15` - сковородки).
*   **В категории можно:**
    1.  Отфильтровать продукты.
    2.  Добавить новый продукт.
    3.  Добавить новое свойство (фильтр) продукта. Доступно 3 типа свойства:
        *   `NUMBER`
        *   `FLOAT`
        *   `STRING_CLASSIFIER` (справочник)

### Справочник
*   При добавлении свойства с типом `STRING_CLASSIFIER` (справочник), его значения можно редактировать впоследствии.

### Продукты
*   В продукт можно перейти из каталога.
*   **Продукт можно:**
    1.  **Купить** – добавить в корзину.
    2.  **Отредактировать свойства:**
        *   Каждое по отдельности, перейдя по ссылке в названии свойства.
        *   Обновить сразу все, изменив значения на форме продукта и нажав кнопку «Обновить» (реализация через цикл в контроллере и репозитории).
    3.  **Добавить новое свойство**, если оно было ранее создано для категории. Для свойства-справочника можно добавить или удалить значение.
    4.  **Удалить свойство** продукта.

### Корзина
*   Сессионная корзина обновляется при изменении её значения в базе данных.
*   Доступна для перехода в верхнем углу экрана в любой момент.
*   **При переходе в корзину отображается:**
    *   Список продуктов.
    *   Количество каждого продукта.
    *   Стоимость каждого продукта.
    *   Суммарная стоимость корзины.
    *   Общее количество продуктов в корзине.
*   **Функции в корзине:**
    1.  **Чекбокс у продукта:** обновляет продукт в корзине и редактирует информацию о заказе.
        *   Если галочка установлена – продукт **не учитывается** при пересчете заказа.
        *   Если галочка снята – продукт **учитывается** при пересчете заказа.
    2.  **Изменение количества продукта:** отправляет запрос на обновление, в результате пересчитывается количество и стоимость продукта в корзине.
    3.  **Формирование заказа:** выбранный заказ проходит проверку на наличие продуктов с использованием **пессимистической блокировки (`FOR SHARE`)**, которая блокирует возможность обновления продукта.

### Профиль
*   Доступен для перехода в верхнем углу экрана в любой момент.
*   Отображает информацию о пользователе, которую можно редактировать.
*   При переключении вкладки отображаются ранее оформленные пользователем заказы. Любой заказ можно просмотреть детально.
